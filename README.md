السيناريو
لقد تم توظيفك مؤخرًا كمطور في شركة ناشئة للتمويل الصغير تهدف إلى تمكين وتوفير الفرص للأفراد ذوي الدخل المنخفض. يستخدم الفريق الأساسي حاليًا Subversion (SVN) لإدارة الشيفرة. يرغبون في الانتقال تدريجيًا بشيفرتهم إلى Git. تم طلب منك استضافة الشيفرة النموذجية لحساب الفائدة البسيطة على GitHub في مستودع جديد كخطوة أولى في هذه الرحلة. لن تقوم فقط باستضافة السكربت، بل ستتبع أيضًا أفضل الممارسات التي تم تقديمها في هذه الدورة وتقوم بإنشاء مستندات داعمة للمشروع مفتوح المصدر بما في ذلك مدونة قواعد السلوك وإرشادات المساهمة. بالإضافة إلى ذلك، يجب أن يكون المستودع متاحًا للمجتمع بموجب رخصة Apache 2.0.

الأهداف
بعد إكمال هذا المختبر، ستكون قد أظهرت أنك قادر على:

إنشاء مستودع جديد في حسابك على GitHub.
اختيار الترخيص المناسب لمشروعك.
إنشاء ملف README.md يشرح غرض المشروع.
إنشاء مدونة سلوك بصيغة markdown تشرح كيف تريد أن يتصرف المجتمع ويتفاعل مع بعضه البعض.
إنشاء إرشادات المساهمة بصيغة markdown تخبر المجتمع كيف يمكنهم المساهمة.
تسجيل الملفات الجديدة في المستودع.
